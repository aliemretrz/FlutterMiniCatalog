# 📱 MiniKatalog App

Flutter ile geliştirilmiş Apple ürün kataloğu uygulaması.
Ürün verileri REST API üzerinden çekilmekte olup listeleme, detay ve sepet özellikleri sunulmaktadır.

## ✨ Özellikler

- Ürün listeleme ve arama
- Ürün detay sayfası
- Sepet yönetimi

## 🛠 Kullanılan Teknolojiler

- Flutter 3.41.9  
- Dart 3.11.5
- DevTools 2.54.2
- REST API (wantapi.com) Bu proje kapsamında kullanılan veriler eğitim ve demo amaçlıdır!

## 🚀 Çalıştırma

1. Repoyu klonla:
```bash
   git clone https://github.com/KULLANICI_ADIN/REPO_ADIN.git
```

2. Bağımlılıkları yükle:
```bash
   flutter pub get
```

3. Uygulamayı başlat:
```bash
   flutter run
```
